# 💰 Финансовый Геймер - Школы Казахстана

Интерактивная обучающая игра по финансовой грамотности для учащихся школ Казахстана.

## 🚀 Возможности

- **PWA приложение** - работает на веб и как приложение на Android
- **Офлайн режим** - играйте даже без интернета
- **Отслеживание прогресса** - сохраняется локально на устройстве
- **Интерактивные уровни** - Основы банков, Кредиты, Инвестиции, Бюджет
- **Достижения** - мотивирующая система наград

## 📁 Структура проекта

```
├── index.html              # Главная страница
├── manifest.json           # PWA конфигурация
├── package.json            # Зависимости
├── README.md              # Этот файл
├── src/
│   ├── app.js             # Основное приложение
│   ├── service-worker.js  # Service Worker для PWA
│   ├── styles/
│   │   └── main.css       # Главные стили
│   └── game/
│       ├── game.js        # Логика игры
│       └── levels.js      # Описание уровней
├── assets/                # Иконки, изображения, скриншоты
└── public/                # Статические файлы (если нужны)
```

## 🛠️ Установка и запуск

### Локальная разработка

```bash
# Вариант 1: Python 3
python -m http.server 8000

# Вариант 2: Node.js (если установлен)
npx http-server
```

Откройте в браузере: `http://localhost:8000`

## 📱 Установка как PWA

### На компьютере (Chrome/Edge)
1. Откройте приложение в Chrome или Edge
2. Нажмите адресную строку → иконка "Установить"
3. Приложение установится как независимое окно

### На Android
1. Откройте в Chrome на Android
2. Меню (три точки) → "Установить приложение"
3. Приложение добавится на главный экран

## 🎮 Геймплей
